# versatil-constants

Shared domain constants for the VersatIL imitation learning ecosystem.

## Installation

```bash
pip install versatil-constants
```

## Usage

```python
from versatil_constants import ObsKey, GripperType, TSOCamera, LiberoCamera
```

## Modules

- `shared` -- Constants shared across all worlds (observation keys, gripper types, coordinate systems, orientation representations).
- `tso` -- TSO Robot Testbed world constants.
- `libero` -- Libero simulation world constants.
- `metaworld` -- MetaWorld simulation world constants.
